# LearnTogether - Learn Together with S J A
## Pre-DSA Mastery: C++ & Java (Newbie to Expert)

Welcome to **Learn Together with S J A** — an interactive, dual-track learning ecosystem designed to master fundamental computer science logic, memory management, low-level mechanics, and OOP in both **C++** and **Java** before advancing into **Data Structures and Algorithms (DSA)**.

---

## 🌟 What's Included

### 1. 🖥️ Interactive Web Learning Platform (`index.html`)
Launch `index.html` directly in any modern browser to access:
- **7-Level Curriculum Roadmap**: From foundational syntax to Expert Pre-DSA STL/Collections.
- **Side-by-Side Code Comparator**: Dual C++ vs Java code panels with line-by-line architecture notes & key takeaways by S J A.
- **Memory & Pointer Visualizer**: Step-by-step visual animation of Stack Frames, Heap Allocations (`new`/`delete`), Pointer dereferencing (`*ptr`, `&var`), and JVM Garbage Collection.
- **Practice Sandbox & Challenge Runner**: Solve pre-DSA logic problems (pattern printing, in-place array reversal, etc.) directly in the browser.
- **Module Knowledge Quizzes**: Self-assessment quizzes with immediate feedback.
- **STL vs Collections Reference**: Searchable map of C++ STL containers vs Java Collections equivalents.

---

## 🚀 How to Use & Run

### A. Launching the Web Learning Application
1. Double-click `index.html` or open it in Google Chrome, Microsoft Edge, or Firefox.
2. Explore the tabs to review concepts, compare C++ and Java syntax side-by-side, visualize memory allocation, and solve practice problems.

### B. Running Source Files via Helper Scripts
You can compile and run any C++ or Java file using the provided batch scripts in `scripts/`:

#### C++ Files:
```cmd
scripts\run_cpp.bat src\01_Foundations\Hello_Syntax.cpp
scripts\run_cpp.bat src\05_Memory_Pointers_References\Pointers_DeepDive.cpp
```

#### Java Files:
```cmd
scripts\run_java.bat src\01_Foundations\Hello_Syntax.java
scripts\run_java.bat src\06_OOP_Mastery\Classes_Constructors.java
```
